\section{Related Work}

Multilingual BERT (M-BERT)~\cite{devlin-etal-2019-bert} is a transformer-based language model that has been fine-tuned on monolingual Wikipedia corpora from 104 languages, learning to map text from each of those languages to a shared embedding space. Pires et al.~\cite{pires-etal-2019-multilingual} investigated its cross-lingual generalizability by doing zero-shot transfer. Quantifying typological similarity as the number of shared word-order related features, they find typological similarity to be positively correlated with zero-shot performance. Lauscher et al.~\cite{lauscher-etal-2020-zero} similarly find zero-shot transfer to be most effective across typologically similar languages, but find that few-shot transfer~-- training on as few as 10 examples in the target language~-- yields considerable improvement over zero-shot transfer.

Further improvements in a low-resource setting can be obtained by adding an intermediary step with auxiliary languages. Nooralahzadeh et al.~\cite{nooralahzadeh-etal-2020-zero} use meta-learning as an intermediary step for improved performance on the tasks of natural language inference (NLI) and question answering (QA). In their setup, they first finetune M-BERT on a large, English-language dataset for the task at hand. Next, they use meta-learning to optimize the model parameters for quick adaptation to new languages. In short, it involves taking model parameters $\theta$ from the first stage, fine-tuning on an auxiliary language $i$ to obtain $\theta_i$, and taking the derivative of the loss $\mathcal{L}(\theta_i)$ with respect to the original parameters $\theta$ to update $\theta$ with. The result is a set of parameters optimized for adaptation to a new language. While they find this setup leads to improved zero-shot performance overall, they note that languages which share certain typological features benefit from this setup most.

Langedijk et al.~\cite{langedijk-etal-2022-meta} adapt this setup by using a typologically diverse set of auxiliary languages and focus on the task of dependency parsing. They find improvements over a zero-shot baseline are largest for target languages that are typologically distant from the source language, possibly because the auxiliary languages provide the model with new linguistic information that can later be leveraged. Choenni et al.~\cite{choenni-etal-2023-cross} add language-specific subnetworks to the meta-learning setup. That is, they identify which subsets of parameters are most used when dealing with a given language, and restrict the model to only use that subset when processing that language. Similarly, they find that this setup yields greater improvements for typologically dissimilar source-target pairs. However, a setup that uses subnetworks without using meta-learning found the opposite effect: better improvements for more similar source and target languages.

Merchant et al.~\cite{merchant-etal-2020-happens} investigate how the information encoded by BERT shifts during finetuning. In particular, they train probes to identify various linguistic features from a learned scalar mixing of the representations from each of BERT's layers. They then compare the performance of these probes on a pre-trained BERT with the performance on a BERT-based model finetuned for NLI, QA, and dependency parsing. While finetuning typically does not alter the presence of these features BERT's embeddings much, finetuning for dependency parsing causes syntax-related features to be more clearly identifiable.

Meanwhile, as stated, Choenni \& Shutova~\cite{choenni-shutova-2022-investigating} show that M-BERT carves its embedding space into language-specific subspaces, with typological features encoded jointly across languages. Combining this with Merchant et al.'s~\cite{merchant-etal-2020-happens} findings, it is conceivable that finetuning on a specific language amplifies typological features relevant to that language in the model's parameters. In turn, these features then become more readily available to any target language that shares them, which could explain the effectiveness of multistage cross-lingual transfer.

% Muller et al.~\cite{muller-etal-2021-first} set out to investigate whart parts of M-BERT allow for zero-shot transfer. Their approach involves taking a pre-trained instance of M-BERT, randomly re-initializing one of its layers, fine-tuning it on a source language, and finally evaluating the model both on the source language and on a different target language. They find that random re-initialization of the first six layers mainly harms zero-shot performance on the target language. Meanwhile, performance on the source language or random re-initialization of the deeper layers does not have as big of an effect. As a result, they conclude that the early layers support cross-lingual alignment, whereas the deeper layers are more task-specific and language-agnostic.
